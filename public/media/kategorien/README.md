# Bildplatzhalter für die Kategorie-Kacheln

Die fünf WebP-Dateien wurden mit dem integrierten ImageGen-Werkzeug für Ardore erzeugt. Die Motive illustrieren Trainingssituationen mit fiktiven Personen. Sie zeigen keine Coach-Profile und verwenden keine externen Stockbilder.

Gemeinsamer Bildauftrag: warme, dokumentarische Sportfotografie im Querformat, ohne Beschriftungen, Marken oder Wasserzeichen.

| Datei | Motiv im Bildauftrag |
| --- | --- |
| `fitness.webp` | Kurzhantel-Kniebeuge in einem kleinen Trainingsstudio |
| `yoga.webp` | Yoga-Haltung Krieger II im Tageslicht |
| `pilates.webp` | Kontrollierte Übung auf einem Reformer |
| `ernaehrung.webp` | Hände schneiden frisches Gemüse in einer Küche |
| `kampfsport.webp` | Zwei Erwachsene beim Pratzentraining im Boxstudio |
